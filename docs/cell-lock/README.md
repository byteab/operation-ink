# Door-mounted cell lock

The cell release control is now a compact box attached to the latch side of the barred door, with a green face and keyhole. Approach the box and press **F Unlock** to release the hostage and swing the door open. The former freestanding control pedestal has been removed.

The housing and its interaction point are children of the moving door hinge. They travel with the leaf instead of intersecting it as it opens; the decorative lock adds no separate movement blocker. Existing proximity and solid-occlusion rules still govern activation.

Build and the rescue suite passed, including real-map control sightlines, opened-cell traversal and hostage release/escape. Agent-browser staged the player beside the actual lock and used the native F handler: the door unlocked and opened, the hostage began following, and the lock moved 2.917 m with zero attachment drift. The old pedestal was absent. This is a staged interaction check, not an input-only full mission run.
